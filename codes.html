Codes & Software

Open-source software from the DM‑QFT Collaboration for lattice field theory and generative diffusion models. Explore our research code below, or browse all DM-QFT repositories on GitHub.

DM_U2_LGT

Non-Abelian gauge theory · Python · Lattice gauge equivariant CNNs

Diffusion models for two-dimensional U(2) lattice gauge theory. Includes score-matching training, reverse-SDE and Metropolis-adjusted annealed Langevin (MAALA) sampling, an example trained network, and a notebook for generating configurations and evaluating observables.

Companion code for Generalizable Equivariant Diffusion Models for Non-Abelian Lattice Gauge Theory.

GitHub repository Paper · arXiv Example notebook

DM-for-phi4

Scalar field theory · 2D and 3D · Python / PyTorch

Training, sampling and analysis for diffusion models in two- and three-dimensional scalar φ4 lattice field theory, with code for studying critical sampling and generalization across lattice volumes.

Companion code for Diffusion Models for Sampling Near Criticality in Lattice Field Theories.

GitHub repository Paper · arXiv 2D code 3D code

DMasSQ

Stochastic quantization · Jupyter notebook · PyTorch · MIT license

A self-contained notebook introducing diffusion models as stochastic quantization through two-dimensional scalar φ4 lattice field theory. Run the example locally or in Google Colab.

Companion code for Diffusion Models as Stochastic Quantization in Lattice Field Theory.

GitHub repository Paper · arXiv Tutorial notebook
